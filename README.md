VidCluster

Cluster-driven opportunity discovery for YouTube creators.

VidCluster is an experimental system designed to detect structured content opportunities using cluster intelligence rather than keyword guessing.

This public repository contains:

📊 Validation artifacts

🧪 Pre-registered methodology

📈 Frozen experiment data (V3.3)

🌐 Marketing website source

The core engine and internal experimentation pipelines are maintained in a separate private repository.

Why VidCluster Exists

Most YouTube tools focus on:

Keywords

Volume

Competition scores

VidCluster explores a different idea:

Can structured cluster intelligence detect durable content opportunities before they become saturated?

Instead of isolated keywords, VidCluster analyzes topic clusters, structural intent, and ecosystem relationships.
